# salvaromanelli.github.io

Mi portfolio: música, sets y los proyectos que construyo.

👉 **https://salvaromanelli.github.io**

Sitio estático (HTML, CSS y JS, sin build) publicado con GitHub Pages.

## Cómo editarlo

- Textos y secciones: `index.html`
- Colores: las variables al principio de `assets/css/style.css`
- Imágenes: `assets/img/`

Para verlo en tu compu: `python3 -m http.server` en esta carpeta y abrí http://localhost:8000
